# Centre for Precision Psychiatry

This GitHub organisation hosts miscellaneous repositories for code projects and research activities associated with:

- The **[Centre for Precision Psychiatry (CPP)](https://www.med.uio.no/klinmed/english/research/centres/precision-psychiatry/)** at the University of Oslo (UiO)
- The **[Precision Psychiatry Research Group](https://www.ous-research.no/pp)** at Oslo University Hospital (OUS)

Together, CPP@UiO and the Precision Psychiatry Research Group@OUS form a joint centre working to improve the understanding, diagnosis, and treatment of psychiatric disorders through precision medicine approaches.
